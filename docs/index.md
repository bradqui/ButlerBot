# ButlerBot Handbook

ButlerBot is our server's resident robot butler: overqualified, mildly put-upon, and genuinely helpful. This handbook explains everything it can do, organized by what you want to get done.

## Three ways to get help

| You want… | Do this |
|---|---|
| To ask in plain English | `!butler how do I start a game vote?`, or just @mention ButlerBot. See [Asking ButlerBot]({{ '/butler/' | relative_url }}). |
| Details on one command | `!help <command>`, for example `!help games own` |
| The big picture | You're in the right place. Pick a topic below. |

## How to read commands

Commands start with `!`. In usages:
- `<angle brackets>` mean required.
- `[square brackets]` mean optional.

Don't type the brackets: `!games own <game>` means you type `!games own Deadlock`.
