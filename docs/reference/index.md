# Command reference

This section lists every command ButlerBot has, generated straight from the running bot. It appears here after the bot owner runs `!handbook export`.

Until then:
- In Discord, `!help <command>` shows any command's usage, who can use it and what it does.
- The topic pages in this handbook explain everything by task.
