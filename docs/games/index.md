# Games

ButlerBot keeps track of the games everyone owns and has installed. It uses that to find something you can all play, run game nights, and settle what to play with a vote.

- **[Your games]({{ '/games/library/' | relative_url }}):** your library, profile setup, favorites and wishlist.
- **[Game nights]({{ '/games/nights/' | relative_url }}):** sessions, weekly game nights, votes, and finding players.

All game commands start with `!games` (or `!game`, `!gm`). Most also have a slash version, like `/games own`, with name autocomplete.
